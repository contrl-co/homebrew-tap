# CONTRL Homebrew Tap

Homebrew formulae for CONTRL command-line tools.

## Formulae

| Formula | Description |
| --- | --- |
| `crlc` | CRL (CONTRL Rule Language) toolchain: lint, compile, fmt, eval, graph |

## Install tap

```sh
brew tap contrl-co/tap
```

## Installing CRL

```sh
brew install contrl-co/tap/crlc
```

Formula updates are published by the
[CRL release workflow](https://github.com/contrl-co/crl/actions). Changes to
this repository require a pull request, a green `Gate summary`, and an
independent CODEOWNER approval.
