# CONTRL Homebrew Tap

Homebrew formulae for CONTRL command-line tools.

## Formulae

| Formula | Description |
|---|---|
| `crlc` | CRL (CONTRL Rule Language) toolchain: lint, compile, fmt, eval, graph |

## Install tap

```sh
brew tap contrl-group/tap https://gitlab.com/contrl-group/homebrew-tap.git
brew trust contrl-group/tap
```

## Installing CRL
```sh
brew install crlc
```
